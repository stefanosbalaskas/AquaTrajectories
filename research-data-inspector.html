Research-data privacy

This inspection does not send selected file bytes to GitHub, OpenAI, Zenodo or any backend: JavaScript reads the file object locally using File.text(). It computes only schema and temporal checks; it is not an ethics approval, automated fish identity adjudication, physical metrology assessment or an end-to-end scientific benchmark. For official computations, validate data with the released R functions.
