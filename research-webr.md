# Run actual R mathematics in your browser

These curated examples run in **real R** through webR WebAssembly. They
use base R for deterministic kinematics, school-heading polarization and
clock alignment. The complete AquaTrajectories package is **not
installed in webR**. An optional, separately labelled module loads
byte-identical v0.1.1 R source definitions for the track model,
kinematics and group metrics. This is source execution, not a compiled
installed WebAssembly package; its full examples belong in your local R
installation.

## Reproducibility and privacy boundary

The code shown above is generated from these controls and executed in a
local browser worker. No user video or file is submitted. Initializing
webR downloads the interpreter from a third-party CDN; it is therefore
not an offline-only operation. Standard presets are base-R
demonstrations. The optional native-source preset uses verbatim v0.1.1 R
definitions (tracks.R and kinematics.R); this does not certify
full-package WebAssembly compatibility or empirical datasets.
