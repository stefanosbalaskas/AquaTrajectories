# Milestone 07 — Independent real-data R/Python numerical parity (20 November 2026)

## Qualification result: PASS

This is a **post-run empirical software audit**, not independent fish identity or physical metrology certification. It compares the frozen native R report, independent Python report, and source CSV rows obtained from the actual five-sequence BrackishMOT dual-path run.

- Original real BrackishMOT recordings: **5** (brackishMOT-23, -55, -74, -93, -98).
- Recorded acquisition frames: **868**; complete analysis-path/frame records: **1,736**.
- Publisher reference fish observations: **6,621**; actual model-generated ByteTrack observations: **2,830**; total **9,451**.
- Source path/sequence scopes: **10** (5 recordings × 2 independently scoped inputs).
- Executed native R vs independent Python parity: **90/90 metrics PASS** (10 × 9).
- Maximum absolute difference in eligible observed aggregate path displacement: **1.4915713109076023e-10 image px**.
- A separate calculation directly from the input frame and observation CSVs reproduced **180/180** independent comparisons against the R and Python summaries; no source-scope collisions, invalid frame references or duplicate (frame, track ID) observations were found.
- Uploaded manifest SHA-256 matches: **3/3 input files**, **69/69 R outputs**, and **68/68 Python outputs**, totaling **140/140**.
- **20** source-comparative figure families per report, each rendered as SVG, PDF and PNG; original report artifacts are kept outside GitHub.
- The input provenance independently **reports** 906 previously verified M06 frozen source files. Those source images were not part of the three M07 evidence archives and were **not rehashed during this particular post-run audit**.

## Explicit limits

- **No measured frame timestamps:** frame number is not elapsed seconds; no px/s, cm/s, physical acceleration, event duration or physiological recovery measure is reported.
- **No camera metrology:** 2D image-pixel displacement cannot be interpreted as physical XYZ or real swimming distance.
- **No newly re-adjudicated biological identities:** publisher labels retain their original scientific limitations, and ByteTrack IDs do not certify the same fish across time or cameras.
- **No replicated treatment or event design:** the results do not establish feeding, stress, welfare, causal inference or independent experimental-tank effects.
- The poor external model-based detection/identity performance reported separately in Milestone 06 is **not improved or relabelled as biological validity** by this software parity pass.

**Conclusion:** Milestone 07 source-integrity, numerical reproducibility and native-R-versus-independent-Python real-data computation gates are **closed — PASS**. Independent biological/physical validation remains a distinct research milestone.
