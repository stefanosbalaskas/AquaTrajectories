# CRAN release qualification: aquaTrajectories 0.1.2

The public GitHub release and Zenodo DOI for 0.1.1 are already published:
https://doi.org/10.5281/zenodo.24262905. They are not a CRAN publication.

**CRAN candidate: 0.1.2.** Distinct versioning avoids silently changing the
already archived source tag. Do not publish the new tag or submit to CRAN
until exact-source qualification passes.

## CRAN requirements and commands

CRAN policy: https://cran.r-project.org/web/packages/policies.html
Submission checklist: https://cran.r-project.org/web/packages/submission_checklist.html

From the repository root containing `DESCRIPTION`, use a current R
installation:

```bash
R CMD build .
R CMD check --as-cran aquaTrajectories_0.1.2.tar.gz
```

The real source tarball must show **zero errors and zero warnings**.
All Notes need individual review and explanation, if unavoidable.
The automated GitHub workflow also archives the built tarball for review.

## Source validation

1. Check the plain-source R package on Ubuntu R-devel, Windows, and macOS.
2. Verify `CITATION.cff` remains GitHub-only via `.Rbuildignore`; R CMD
   check previously raised a NOTE when this file entered the source tarball.
3. Confirm documentation generated by roxygen matches tracked `man/` pages.
4. Confirm that the examples run in check, including on CRAN without Python.
5. Confirm optional `rgl`, `fdapace`, `nlme` paths fail gracefully when not
   installed and do not require proprietary inputs.
6. Check there are no excessive runtime, internet, file-writing or
   parallel-worker behaviours in examples and tests.
7. Manually inspect all shipped scripts, licenses and third-party attribution.
8. Fill the full evidence and outcomes into `cran-comments.md`, then upload
   through https://cran.r-project.org/submit.html and confirm the email.

## Important distinction

CRAN distributes a general R package; source availability, engineering tests,
and synthetic demonstrations are not independent biological science validation.
