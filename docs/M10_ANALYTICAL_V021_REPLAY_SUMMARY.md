# M10 — Exact v0.2.1 analytical replay: public evidence summary

**Evidence snapshot:** 23 November 2026  
**Software:** [AquaTrajectories v0.2.1](https://github.com/stefanosbalaskas/AquaTrajectories/releases/tag/v0.2.1) (published R source archive).  
**Scope:** historical, five-sequence BrackishMOT reference-conditional *R analytical replay* on Windows 11 / R 4.6.1, not renewed video inference or independent fish annotation. This record is a bounded audit summary, not a deposit of the original third-party source data.

## What was verified

1. The local replay authenticated the published `aquaTrajectories_0.2.1.tar.gz` source archive against release SHA-256 `8f3af900030b618f842b390a403e4e0d468f04eea2598537787a3ab0a2c79331`, and installed the package in an isolated R library.
2. The previously frozen M07 source input hashes were checked against their provenance record. M06 inference and M08 matching ledgers were **reused**, not regenerated by a new detector/tracker run.
3. The tagged R functions recomputed M07 image-space frame-index analysis and M08 reference-conditional measurements. The M08 comparison ledger contained **65/65 passing R–Python checks** across five original sequences: **59 matching numerical values** and **six appropriately undefined in both**; the 65 rows were identical to the archived historical comparison ledger.
4. The primary fixed-denominator source totals remained **868 original acquisition frames**, **6,621 publisher-reference fish positions**, **2,830 external-model tracker observation rows**, **374 matched reference positions** at IoU 0.50, **6,498 original reference-adjacent steps**, and **265 steps** with both endpoints matched to the same local model-track ID.
5. The corresponding matched fractions were **374/6,621 = 5.65%** for original reference positions and **265/6,498 = 4.08%** for original reference-adjacent steps. These are tracking-output coverage conditional on the publisher reference, **not** stand-alone YOLO detection recall, independently verified persistent biological IDs or whole-school movement reliability.

**Interpretation:** these tests support the numerical reproducibility of the specified source-to-analysis workflow with a pinned R release. They do not imply that the external tracker recovered enough individuals to estimate complete biological trajectories. The paired-position errors are calculated only on matched observations and are subject to substantial selection.

## Independent software release qualification is separate

The v0.2.1 release qualifies the exact R source archive using strict zero-error/warning/note `R CMD check` on **Linux, Windows and macOS**, **188 documented R exports**, **100.0000% instrumented R expression coverage** and zero uncovered expressions, and a pinned synthetic trajectory-to-report example with an independent Python numerical oracle. **Coverage refers to executed software expressions, not fish-tracking accuracy or scientific uncertainty coverage.**

## What the M10 replay did not test

- No retraining, new YOLO/ByteTrack model inference or new hidden-test performance estimate.
- No prediction-blind human adjudication of persistent biological fish identities.
- No authenticated physical shutter/exposure timestamps, cm/s or independent underwater 3D target survey.
- No independent tank replication, feeding-effect inference, welfare diagnosis, causal treatment effect or physical actuator qualification.
- No claim of a new independently publicly downloadable real-data evidence bundle: original media, model weights, selected annotation rows and private/local evidence remain outside this repository. Source acquisition and rights must be handled separately.
