Reproducibility and privacy boundary
The code shown above is generated from these controls and executed in a local browser worker. No user video or file is submitted. Initializing webR downloads the interpreter from a third-party CDN; it is therefore not an offline-only operation. Results are base R demonstrations, not a substitute for validating AquaTrajectories' own compiled dependencies or empirical datasets.
