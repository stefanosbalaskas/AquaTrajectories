# Import long-form idtracker.ai tracks after explicit reshaping

Import long-form idtracker.ai tracks after explicit reshaping

## Usage

``` r
aqt_import_idtracker(path, session_id, camera_id)
```

## Arguments

- path:

  CSV path containing track_id, time_s, x, y.

- session_id:

  Session identifier.

- camera_id:

  Camera identifier.
