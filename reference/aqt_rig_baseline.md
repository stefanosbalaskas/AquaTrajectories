# Calculate camera-centre separation under a pinhole model

Calculate camera-centre separation under a pinhole model

## Usage

``` r
aqt_rig_baseline(rig, camera_a, camera_b)
```

## Arguments

- rig:

  Calibrated camera rig.

- camera_a, camera_b:

  Camera labels in rig.

## Value

Distance between camera centres in rig world-coordinate units.
