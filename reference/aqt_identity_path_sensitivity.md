# Propagate alternate fish identities into coherent swimming paths

Propagate alternate fish identities into coherent swimming paths

## Usage

``` r
aqt_identity_path_sensitivity(scenarios, max_gap_s = Inf)
```

## Arguments

- scenarios:

  Identity uncertainty object.

- max_gap_s:

  Largest valid inter-frame movement segment.

## Value

Per-scenario path lengths and speed with exact fish ID scope.
