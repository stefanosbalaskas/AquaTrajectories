# Export a sealed evidence report with tables, figure and SHA-256 ledger

Export a sealed evidence report with tables, figure and SHA-256 ledger

## Usage

``` r
aqt_evidence_export(report, directory)
```

## Arguments

- report:

  Output of aqt_evidence_report().

- directory:

  Fresh output directory; overwrite is prohibited.

## Value

New directory, invisibly. No source input is modified.
